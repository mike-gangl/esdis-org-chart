## Purpose
Delivers and operates the shared tools, platforms, and infrastructure that power ingest/archive, discovery/distribution, and visualization across ESDIS, using Agile/SAFe practices and the Enterprise Tools Repository / TDE workflow.

## Deliverables
- I&A (Ingest & Archive): Cumulus/C-Cumulus, Earthdata Pub, Cloud Upload Environment, data quality/preservation (SAFe I&A Train)
- Discovery and Distribution: Harmony, AppEEARS, Vertex, LANCE, Earthdata Search, Earthdata Login, CMR
- Visualization: Worldview/GIBS, EGIS, FIRMS
- Cloud platform operations (GAP/SCIP, networks, security)
- Metrics, BI, and the Enterprise Tools Repository

## Members / Roles
- Leadership — Lead, Systems Engineer, Portfolio Lead, System-Level Scrum Master
- UI/UX Team
- Core Tools and Services
  - I&A — Leadership Team, Cumulus Core Team, Dashboard/Operator Experience Team, Cumulus Task Team, Data Operations Teams (3, grouped by DAAC)
  - Discovery and Distribution — sub-teams to be added {gap}
  - Visualization — sub-teams to be added {gap}
- Infrastructure Services — Cloud Platform, Metrics, CI/CD & Earthdata Code Collaborative

## Dependencies
- EED contract (accountable for Cumulus Core Team and Dashboard/Operator Experience Team work)
- DAAC Mission Data Teams and Data Providers (coordination with Data Operations Teams)
- Systems Engineering (I&A Systems Engineer handles requirements/V&V/ICDs)
