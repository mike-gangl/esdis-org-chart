## Purpose
Connects ESDIS data holdings to the science community: covers external science engagement (ASSETs), user needs capture, user support, and internal enterprise science support.

## Deliverables
- ASSET programs across the seven science spheres (Atmosphere, Hydrosphere, Cryosphere, Biosphere, Geosphere, X-ASSET)
- User needs capture and requirements feeding into enterprise roadmaps
- Cross-ASSET enterprise user support (Consolidated User Support Team)
- ESDIS Connect liaison deliverables (coordination, user dev materials, content quality, support/enablement, continuous improvement)
- Open science championing via Openscapes

## Members / Roles
- Leadership Team (6) — Science Enablement Lead (chairs ASSET Science Council), Science Enablement Lead Scientist, Applications Liaison, ESDIS Connect Strategist, User Needs Coordinator, Openscapes Team Lead
- ASSETs — Atmosphere, Hydrosphere, Cryosphere, Biosphere, Geosphere, X-ASSET (each with ASSET Lead, Science Data Support, User Needs/User Support, User Working Group)
- ASSET Science Council
- User Needs Team
- Consolidated User Support Team
- ESDIS Connect
- Openscapes Team

## Dependencies
- ESDS Connections / Digital Strategy and User Development (ESDIS Connect liaison)
- Earth Action, ESSRP program scientists, NASA ARSET, Mission Science Teams
- Data Stewardship (Mission Stewardship Leads grouped by ASSET)
